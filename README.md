## 💻 Descrição
Nesse projeto, desenvolvi uma aplicação com Vite. Apesar de serem poucas funcionalidades a aplicação é para mostrar o trabalho da Arquiteta Luisa Simões, que contém as seguintes funcionalidades:

- Listagem de projetos
- Galeria de imagens
- Contato direto com a arquiteta
